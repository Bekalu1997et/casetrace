# CASETRACE Development Skills

This package contains 12 agent-facing Markdown files in four skill directories.

Start with `skills/case-trace-development/skill.md` then open the relevant specialist skill and its companion reference files.

**Authority:** repository `AGENT.md`, user request, and authoritative interface contracts take precedence over illustrative snippets in these skills.

**Note:** examples are implementation patterns, not newly approved API contracts. File names mentioned in these skills should be mapped to their actual repository names where different.
